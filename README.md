# Project Explorer · GitHub 开源项目精选

每天发现 GitHub 上优秀、有趣、实用的开源项目，深入核实质量、维护状况、许可证和使用方式后写成研究报告。

- 每天更新一期，每期推荐 3 个项目
- 每期完整报告见 `history/`，按日期命名
- 所有推荐过的项目汇总在 `database/projects.md`，避免 90 天内重复推荐
- 分类索引见 `categories/`

## 目录结构

```
project-explorer/
├── README.md
├── history/            # 每期完整报告，按日期命名
├── database/
│   └── projects.md     # 全部推荐项目总库（去重用）
└── categories/         # 按分类整理的项目索引
    ├── productivity.md
    ├── ai-tools.md
    ├── developer-tools.md
    ├── self-hosted.md

```

## 筛选原则

- 有真实使用场景，解决具体问题，功能完整
- README 清晰，有安装和使用说明，许可证明确
- 仍在维护，近期有提交、版本发布或活跃讨论
- 兼顾热门项目与 Star 不高但质量好的小众项目
- 不只看 Star，不只推开发者工具，每期都有眼前一亮的发现
