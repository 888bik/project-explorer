## Glance

- GitHub 地址：https://github.com/glanceapp/glance
- 项目官网：未在仓库主页注明；文档见仓库内 docs/ 目录，另有社区 widgets 仓库 https://github.com/glanceapp/community-widgets
- 项目分类：自托管与个人服务器 / 效率与生产力
- Star 数量：38,056（查询于 2026-11-07）
- 最近更新时间：2026-11-07（仓库创建于 2024-04-27；最新 Release v0.8.7，发布于 2026-10-15）
- 开源许可证：AGPL-3.0
- 开发语言：Go
- 支持平台：Docker、Linux、macOS、Windows（单文件二进制 + Docker 镜像；Web 界面，移动端适配）

### 1. 它是什么？（通俗易懂）

Glance 是一个轻量、自托管的个人仪表盘 / 浏览器起始页。它把 RSS 订阅、Reddit、Hacker News、天气、YouTube 频道更新、Twitch 直播、市场行情、Docker 容器状态、服务器状态等所有信息流聚合到一个页面上，打开浏览器就能一眼看完。

### 2. 它能解决什么问题？（实际场景与痛点）

- 每天要刷的信息源散落在各处：RSS 阅读器、Reddit、Hacker News、天气应用、视频网站，来回切换很碎。
- 想在自己的服务器上搭一个"个人首页"，但 Homepage、Homer 等方案有的偏重、有的配置繁琐。
- 手机上也想随时看一眼家里的服务状态、Docker 容器是不是挂了，缺一个轻量的移动端入口。

### 3. 核心功能（3-5 个）

- **几十种 widgets**：RSS、Reddit 帖子、Hacker News、天气预报、YouTube 频道更新、Twitch 直播、市场行情、Docker 容器状态、服务器状态、自定义 widget；还有独立的社区 widgets 仓库可以扩展。
- **极轻极快**：单个二进制不到 20MB，依赖极少；无缓存页面通常 1 秒内加载完成。
- **高度可定制**：多页面 / 多标签、每种 widget 都有大量配置项、多种样式、自定义 CSS、主题（调几个数字就能自制主题）。
- **移动端优化**：专门为手机做了适配，出门也能看。
- **配置热重载**：改 YAML 配置文件保存后立即生效，不用重启服务。

### 4. 为什么值得推荐？（亮点、设计思路、同类优势）

- 与 Homepage、Homer、Dashy 等同类仪表盘相比，Glance 把"轻量"和"完成度"兼顾得最好：Go 单文件、资源占用极低，非常适合只有 2 核 1.7GB 内存的小服务器——比如同一台机器上已经跑着 Faved 书签服务，Glance 可以作为"首页入口"把它和服务器状态收在一起。
- 配置就是直观的 YAML，官方还提供预配置页面（preconfigured pages），新手可以直接抄一份改。
- 38,056 Star、从 2024 年 4 月持续维护至今，更新到当天，不是昙花一现的项目。

### 5. 如何使用？（安装、部署或快速体验入口）

- Docker（官方推荐）：按 README 的安装命令拉取官方 docker-compose-template 模板文件，`docker compose up -d` 启动，浏览器打开服务器的 8080 端口（默认端口，可在配置文件里改）。
- 也可以直接从 GitHub Releases 下载单文件二进制运行；配置文件为 YAML（glance.yml），详细配置见仓库 docs/configuration.md。
- 注意：要从外网访问，记得在服务器防火墙 / 安全组放行对应端口；配置里支持用 `${ENV_VAR}` 引用环境变量。

### 6. 适合什么人？（普通用户、开发者、学生、技术爱好者）

- 有 VPS / 家庭实验室，想搭一个个人首页的人；每天刷 RSS、Reddit、Hacker News 的信息流重度用户；想看看 Go 如何写出轻量服务的开发者。

### 7. 推荐指数（实用性、完成度、维护情况、探索价值综合判断，给等级及理由）

★★★★★（5/5）。轻、快、稳、配置直观，部署在小内存服务器上毫无压力；38k Star 与持续两年的维护是最好的背书。本期最稳的"装了就用得上"的选择。

## Komi Store

- GitHub 地址：https://github.com/komi-store/komi-store
- 项目官网：https://www.komistore.app
- 项目分类：Android 与隐私 / 效率与生产力
- Star 数量：20,403（查询于 2026-11-07）
- 最近更新时间：2026-11-07（仓库创建于 2025-11-21；最新 Release v1.9.4，发布于 2026-10-24）
- 开源许可证：Apache-2.0
- 开发语言：Kotlin（Compose Multiplatform）
- 支持平台：Android、Windows、macOS、Linux

### 1. 它是什么？（通俗易懂）

Komi Store（曾用名 GitHub Store）是一个跨平台的开源应用商店，专门收录发布在 GitHub、Codeberg 与其他 Forgejo / Gitea 代码托管平台上的开源软件。可以理解为"开源软件的 F-Droid + Obtainium 升级版"：能逛、能发现、能一键安装。

### 2. 它能解决什么问题？（实际场景与痛点）

- 很多好用的开源 App 只在 GitHub 发 Release，不上架应用商店；逐个去仓库翻 Release、手动下载 APK 很麻烦。
- Obtainium 能盯住更新，但没有"逛商店"的发现体验；F-Droid 收录要经过审核，版本常常滞后于上游。
- 桌面端也想用同一套方式安装开源软件，不用再去各个官网翻下载页。

### 3. 核心功能（3-5 个）

- **浏览与发现**：直接浏览 GitHub、Codeberg、Forgejo 上发布的开源应用，按分类或热度发现新软件。
- **一键安装与更新跟踪**：从 Release 一键安装应用，并跟踪已装应用的新版本发布。
- **跨平台**：同一套体验覆盖 Android、Windows、macOS、Linux；v1.9.4 提供 APK、exe / msi、dmg / pkg、deb、AppImage 等完整安装包。
- **直连上游**：版本直接跟随开发者在代码托管平台的 Release，不经过中间商店审核。

### 4. 为什么值得推荐？（亮点、设计思路、同类优势）

- 使用场景高度契合 Android 玩家：平时从 GitHub 装 Shizuku、Hail、搞机工具箱这类工具的人，用 Komi Store 可以把"翻 Release 下 APK"变成逛商店。
- 势头很猛：2025 年 11 月 21 日才建仓，不到一年冲到 20,403 Star，更新到当天。
- 与 Obtainium 相比多了发现和浏览；与 F-Droid 相比版本直接跟随上游 Release，不用等收录。
- 提醒：仓库 README 顶部有一条与巴勒斯坦相关的声援横幅和 keepandroidopen.org 的呼吁，这是开发者的个人表态，不影响软件功能；介意的用户可自行判断。

### 5. 如何使用？（安装、部署或快速体验入口）

- Android：去 GitHub Releases 下载 v1.9.4 的 APK（约 42.7MB）安装；也可以从官网 https://www.komistore.app 获取。
- 桌面端：Releases 提供 Windows exe / msi（含便携 zip）、macOS dmg / pkg、Linux deb / AppImage。
- 安装后即可浏览发现应用，或添加关注的仓库，一键安装并跟踪更新。

### 6. 适合什么人？（普通用户、开发者、学生、技术爱好者）

- 经常从 GitHub 安装开源 App 的 Android 玩家；用 F-Droid / Obtainium 但觉得发现体验不够好的人；桌面端也想集中管理开源软件的人。

### 7. 推荐指数（实用性、完成度、维护情况、探索价值综合判断，给等级及理由）

★★★★☆（4.5/5）。把"找开源 App"从翻仓库变成逛商店，体验跃升明显；扣半星是因为项目还年轻（不到一年），长期维护与应用审核机制有待时间验证，桌面端安装包单个约 180MB、体积偏大。

## OpenMAIC

- GitHub 地址：https://github.com/THU-MAIC/OpenMAIC
- 项目官网：https://open.maic.chat/（在线演示，无需安装）
- 项目分类：AI 与智能体 / AI 教育
- Star 数量：42,841（查询于 2026-11-07）
- 最近更新时间：2026-11-07（仓库创建于 2026-03-11；最新 Release v1.4.1，发布于 2026-11-06）
- 开源许可证：MIT
- 开发语言：TypeScript（Next.js 16 + React 19 + PostgreSQL 16）
- 支持平台：Web（在线演示零安装；自托管需要 Node.js ≥ 22.19、pnpm ≥ 10、PostgreSQL 16）

### 1. 它是什么？（通俗易懂）

OpenMAIC（Open Multi-Agent Interactive Classroom）是清华大学 MAIC 实验室开源的"多智能体互动课堂"。输入一个主题或一份文档，一键生成一堂有 AI 老师讲课、AI 同学讨论、白板板书、语音讲解的互动课；学完还能把整堂课导出成 PPTX 或离线 HTML 文件带走。

### 2. 它能解决什么问题？（实际场景与痛点）

- 自学新概念时只有干巴巴的文档或教材，缺一个能讲、能问、能互动的"老师"。
- 想把自己的笔记、课件变成可交互的学习材料，而不是静态页面。
- "做中学"缺带练的人：项目制学习 PBL v3 让学习者边做项目边理解概念，AI 导师全程带练、给里程碑反馈。

### 3. 核心功能（3-5 个）

- **多智能体课堂**：AI 老师讲课、AI 同学参与讨论、白板绘图、TTS 语音讲解，还原真实课堂的互动感。
- **一键生成课程**：任意主题或上传的文档都能生成课程；上传的资料进入个人知识库，支持 @ 引用，供智能体检索和整理。
- **项目制学习 PBL v3**（v1.4.0 新功能）：把概念变成动手任务，AI 导师带你从需求、设计一路做到实现，里程碑给阶段反馈和个人学习报告，进度可随时续学。
- **课堂导出**：整堂课导出为保留每个场景的 PPTX，或单个离线 HTML 文件，随身带走、离线也能看。
- **模型灵活**：支持 OpenAI、Anthropic、DeepSeek、Kimi、Qwen、Ollama 与本地模型（Lemonade）、FunASR 本地语音识别，一个 DeepSeek Key 即可点亮聊天、联网搜索与抓取；还可接入 OpenClaw 等 Agent 工作台。

### 4. 为什么值得推荐？（亮点、设计思路、同类优势）

- 本期"眼前一亮"之选：Agent 时代正在从"框架与基础设施"走向"开箱即用的成品应用"，OpenMAIC 就是代表作——它不是又一个 Agent 框架，而是一个直接能用的学习产品。
- 对学生的学习场景尤其对口：手头有大量学习笔记、正在啃新技术的人，可以把笔记和教材变成互动课堂；PBL v3 的"做中学"也契合"项目先行"的学法。
- 迭代极快：v1.4.1 就在昨天（2026-11-06）发布，v1.4.0 的 PBL v3 是 11 月 4 日刚上的；中英文体验指南齐全。
- MIT 协议，技术栈（Next.js 16 + React 19 + TypeScript）是主流前端栈，源码可读性高，适合边用边学。

### 5. 如何使用？（安装、部署或快速体验入口）

- 最快体验：直接打开在线演示 https://open.maic.chat/，无需安装。
- 自托管：克隆仓库，`pnpm install`，复制 `.env.example` 与 `openmaic.example.yml` 填入 API Key（以 DeepSeek 为例，一个 Key 即可点亮聊天、联网搜索与抓取），`pnpm db:up` 用 Docker 起一个 PostgreSQL 16，启动即可。需要 Node.js ≥ 22.19、pnpm ≥ 10。
- 注意：1.2.x 起为 server-first 架构，需要常驻服务器与 PostgreSQL；从 1.1.x 升级前先读升级说明（涉及数据库迁移，升级是单向的）。

### 6. 适合什么人？（普通用户、开发者、学生、技术爱好者）

- 自学新技术、备考、做课程的学生与开发者；想把笔记变成互动课的人；想研究多智能体编排、Next.js 16 实践的开发者。

### 7. 推荐指数（实用性、完成度、维护情况、探索价值综合判断，给等级及理由）

★★★★☆（4.5/5）。创意与完成度拉满，在线演示零门槛；扣半星是因为自托管有门槛（PostgreSQL + API Key + 常驻服务），且 1.4.x 的升级是单向的、需要先读 Breaking Changes。
